## Description

> Les scènes **référencent** les palettes (SCN-008) : modifier une palette met à jour immédiatement toutes les scènes (et la sortie si elles jouent).

**Critère d'acceptation** : Modifier « Piste centre » pendant une scène → lyres se déplacent.
