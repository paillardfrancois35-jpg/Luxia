## Description

> **Perte du PC** : si l'interface DMX ne reçoit plus de trame valide pendant **2 s**, elle émet un blackout complet (tous canaux à 0, fumée comprise).

**Critère d'acceptation** : Débrancher l'USB → noir en ≤ 2 s (déjà présent dans le POC).

## Réalisation

- `firmware/arduino-dmx/arduino-dmx.ino`
