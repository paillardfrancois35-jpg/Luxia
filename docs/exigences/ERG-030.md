## Description

> **En-têtes de couche toujours visibles** (demande de l'utilisateur, essai P6) : dans les Colonnes, le nom de la couche, ◀ ▶ ■ et le master restent en haut ; seules les scènes défilent verticalement ; un défilement horizontal (colonnes trop nombreuses) déplace en-têtes et scènes ensemble, alignés.

**Critère d'acceptation** : Capture 1366 × 768 ; essai.

## Réalisation

- `ColumnsPanelView` : deux listes des mêmes couches, en-têtes (rangée fixe) et scènes (dans leur propre défilement vertical), dans un défilement horizontal commun ; largeur partagée (`Board`) pour garder les colonnes alignées.

## Tests

- Capture « Contrôle - LIVE surcharge » en 1366 × 768 relue (colonnes alignées, en-têtes fixes)
