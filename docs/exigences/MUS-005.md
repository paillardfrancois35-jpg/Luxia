## Description

> Gestion des titres **YouTube** : l'« artiste » est souvent le nom de la chaîne (« XYZ – Topic », « XYZVEVO »), le vrai artiste est dans le titre (« Artiste - Titre (Official Video) ») → séparation artiste / titre (§3.1).

**Critère d'acceptation** : Jeu de test YouTube.
