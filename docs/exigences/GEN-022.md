## Description

> Les couleurs sont manipulées comme des couleurs logiques (rouge, vert, bleu, + blanc/ambre/UV si utiles) et converties selon les émetteurs de chaque appareil (RGB, RGBW, roue de couleur).

**Critère d'acceptation** : Test : couleur « blanc chaud » → valeurs RGB sur PAR RGB, RGBW avec blanc sur PAR RGBW, emplacement le plus proche sur la roue d'une lyre.
