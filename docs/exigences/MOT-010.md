## Description

> Chaque étape a un **fondu d'entrée** puis un **maintien** ; la durée d'une étape = fondu + maintien. Le passage à l'étape suivante a lieu à la fin du maintien.

**Critère d'acceptation** : Étape (fondu 1 s, maintien 2 s) → étape suivante à t = 3 s.
