## Description

> Phase répartie selon l'**ordre de la sélection**, modes linéaire / miroir / groupes / aléatoire.

**Critère d'acceptation** : Chenillard gauche → droite ; miroir du centre vers les bords.

## Réalisation

- `EffectCompiler.Lag` : décalage total en degrés (360 = un cycle réparti), modes linéaire (du premier au dernier), miroir (du centre vers les bords), par groupes (un sur N ensemble : N = 2 → pairs / impairs), aléatoire (ordre tiré une fois pour toutes d'après l'identifiant de l'effet). Sens avant, arrière, aller-retour (`EffectShapes.Directed`).
