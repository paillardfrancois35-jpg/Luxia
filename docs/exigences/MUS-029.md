## Description

> **Export et import JSON** des trois tables (styles, artistes, alias), même format dans les deux sens ; un import ajoute et met à jour, il ne supprime rien (chargement du gros fichier de base de l'utilisateur).

**Critère d'acceptation** : Exporter puis importer dans une base vide redonne la même base.
