## Description

> Un **enregistrement de fichier** refusé un court instant par le poste (antivirus, outil de sécurité) est retenté automatiquement ; un échec persistant est signalé clairement.

**Critère d'acceptation** : Fichier verrouillé 60 ms pendant un enregistrement → enregistrement réussi.
