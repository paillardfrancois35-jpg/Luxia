## Description

> Une erreur dans un module secondaire (audio, style, MIDI, simulateur) ne doit ni arrêter le moteur ni la sortie : le module est désactivé et signalé.

**Critère d'acceptation** : Test : exception forcée dans l'analyse audio → lumière continue, alerte en Live.
