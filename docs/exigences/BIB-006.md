## Description

> L'intensité virtuelle est déduite automatiquement (§2.7) ; la propriété **« Suit l'intensité »** est pré-remplie selon le tableau du §2.7 et **modifiable canal par canal** dans l'éditeur (case à cocher).

**Critère d'acceptation** : PAR RGB 3 canaux → R, G, B cochés ; PAR 7 canaux → aucun coché ; décocher B → le bleu ne suit plus le dimmer.
