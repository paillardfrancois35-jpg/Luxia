## Description

> **Mode ÉDITION** : le réglage s'écrit tout de suite dans l'étape choisie de la scène éditée ; l'étape est montrée sur la sortie (C7) ; un geste = une entrée d'annulation, écrite 0,5 s après le dernier mouvement ; « allumer en coloriant » (MOT-041) ; « Retirer de l'étape ».

**Critère d'acceptation** : Tests.

## Réalisation

- `ControlSession.Apply/ApplyValues/Commit/Undo/Redo`, `ControlViewModel.CountDownCommit` (0,5 s).
