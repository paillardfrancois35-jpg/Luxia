## Description

> Aujourd'hui, importer un modèle déjà présent dans la bibliothèque (`Documents\DMX\Bibliothèque\...`) ne fait rien
> (rapport « = déjà dans la bibliothèque, non importé »), sans proposer de le remplacer. Pendant la correction de la
> définition de la lyre Tomshine (BIB-095), l'utilisateur a dû supprimer le fichier à la main avant de pouvoir réimporter
> la version corrigée — pas évident à deviner.

**Comportement attendu** : la fenêtre d'import propose une case à cocher **« Écraser si déjà présent »** (décochée par
défaut, pour ne pas perdre une modification locale par erreur). Le rapport d'import indique alors « ✓ remplacé » au lieu
de « = non importé » pour les modèles concernés.

**Différence avec GEN-053** : GEN-053 concerne la copie du modèle dans le **projet** (patch), avec un rapport d'impacts
sur les scènes existantes (P3, doc 12 §8) — plus complexe, car un canal peut avoir changé de position. BIB-098 concerne
seulement la **bibliothèque personnelle** (aucune scène en jeu à ce stade), donc une simple confirmation suffit.

## Réalisation

- `src/Dmx.UI.Modules.Library/LibraryViewModel.cs` : `OverwriteExisting`, `ImportAsync` remplace le fichier existant (même identifiant conservé, GEN-052 ; version incrémentée par `FixtureLibrary.Save`) et rapporte « ✓ … remplacé ».
- `src/Dmx.UI.Modules.Library/LibraryView.axaml` : case « Écraser si déjà présent » (décochée par défaut).
