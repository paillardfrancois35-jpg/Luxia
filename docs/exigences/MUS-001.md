## Description

> Lecture des sessions média du système ; choix de la session **en cours de lecture** ; si plusieurs jouent, la plus récemment démarrée ; si aucune ne joue, la dernière active.

**Critère d'acceptation** : Spotify + navigateur ouverts → la bonne session suivie.
