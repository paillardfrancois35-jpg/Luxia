## Description

> Les sorties réseau locales (Art-Net) restent autorisées : elles n'utilisent que le réseau local.

**Critère d'acceptation** : —

## Réalisation

- Rien à coder pour l'exigence elle-même (un principe, pas une fonction) : aucune sortie de l'application n'accède à Internet, seul le réseau local est prévu pour Art-Net.

## Tests

- Sans objet (principe vérifié par revue du code des pilotes, tous locaux : Arduino USB série, Simulateur en mémoire, Enregistreur sur disque).
