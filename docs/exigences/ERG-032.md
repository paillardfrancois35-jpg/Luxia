## Description

> **Écran de jeu** (chantier « Contrôle 2 », remplace ERG-010/011/012 et le sélecteur de modes) : pas de mode ; peu de panneaux, grands (Colonnes, Groupes dimmer, Looks, Pilote, Journal) ancrables et détachables ; les retouches en direct (masters, dimmers, couleur rapide) sont temporaires (« Libérer ») ; verrou soirée gardé ; une seule disposition (Contrôle / Spectacle fusionnées, ERG-001/024 reformulées).

**Critère d'acceptation** : Maquette validée ; tests.
