## Description

> Les valeurs peuvent cibler un **appareil**, une **cellule** ou une **sélection** ; une valeur sur une sélection s'applique à tous ses membres présents (y compris ceux ajoutés plus tard à une sélection automatique).

**Critère d'acceptation** : Ajouter un PAR à « Tous les PAR » → la scène le pilote.
