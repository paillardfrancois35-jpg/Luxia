## Description

> **Looks** (F1, §4.8) : `looks.json` (lancer / arrêter des scènes, arrêter une couche, tout arrêter, masters) ; panneau Looks : jouer d'un clic, « Capturer ce qui joue », mettre à jour, renommer, couleur, supprimer ; verrou : jouer seulement ; `valider` signale une référence introuvable. Touches **F1 à F12** = looks 1 à 12 (écran Contrôle) ; déclencheurs MIDI et entrée DMX : à venir.
