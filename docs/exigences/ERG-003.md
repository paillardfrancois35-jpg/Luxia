## Description

> **Grille Pan / Tilt** (composant commun, §5) : un point par appareil, en degrés ; un clic amène la sélection sous le curseur (plusieurs appareils : leur centre, écarts conservés, sans écraser un appareil contre le bord) ; Maj + glisser = réglage fin ; molette = Tilt fin (Maj : Pan, Ctrl : ×10) ; flèches ; **zones interdites** (rouges) et **zone permise** (limites, extérieur assombri, F7) dessinées, déplacées et redimensionnées par **8 poignées**, Suppr pour retirer.

**Critère d'acceptation** : Tests des calculs ; galerie ; essai utilisateur.

## Réalisation

- `Luxia.UI.Controls.PanTiltGrid` (dessin, souris, molette, clavier), `PanTiltGeometry` (calculs), types `PanTiltMarker`, `PanTiltZoneMarker`, `PanTiltRect`, `PanTiltTarget`, `PanTiltZoneRequest`, `PanTiltHandle`, `PanTiltZoneKind`.

## Tests

- PanTiltGeometryTests (repère, bornes, groupe qui garde sa forme au bord, barycentre, poignées, déplacement de zone, degrés)
