# GEN-096 – Pas de mise en veille du PC pendant l'émission

| Champ | Valeur |
|---|---|
| **Statut** | Réalisé, à valider sur matériel |
| **Priorité** | I |
| **Phase** | P0 |
| **Source** | [doc 02 – 14. Robustesse et performances](../02-principes-et-architecture-fonctionnelle.md) |
| **Remarque** | Demande temporaire `SetThreadExecutionState` sur un fil dédié, posée au démarrage du moteur, levée à l'arrêt. |
| **Liens** | D23, GEN-030, GEN-031, GEN-080, Q26 |

## Description

> Tant que l'application émet, le PC **ne se met pas en veille** : demande temporaire au système, propre au processus, sans modifier les réglages du poste (l'écran peut s'éteindre).

**Critère d'acceptation** : PC réglé sur une veille courte : aucune veille pendant l'émission ; veille de nouveau possible après fermeture.
