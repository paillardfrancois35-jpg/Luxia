## Description

> **Flash** (CMD-014) : la scène est appliquée instantanément au-dessus de toutes les couches tant que la commande est maintenue ; au relâchement, retour instantané (ou fondu court réglable).

**Critère d'acceptation** : Test appui/relâche.
