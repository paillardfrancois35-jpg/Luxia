## Description

> **Avance à l'événement** : une scène peut avancer d'étape sur chaque temps (ou tous les N temps / mesures) de l'horloge, ou sur chaque **impulsion** (basses / aigus) (doc 19) au lieu de la durée.

**Critère d'acceptation** : Avance sur impulsion basses : une étape par kick.
