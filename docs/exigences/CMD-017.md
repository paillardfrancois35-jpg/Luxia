## Description

> Commande `MontrerÉtape` (scène, étape (ou aucune) : l'étape éditée est jouée, effets compris, au-dessus des couches et figée sur cette étape (aperçu des effets pendant le réglage, EFF-006)), traitée par : Moteur.

**Critère d'acceptation** : —

## Réalisation

- `ShowStepCommand` (Luxia.Messaging) ; `RenderEngine` : une lecture « étape montrée » à part, fusionnée après toutes les couches (intensité prioritaire, master 1), figée (`Playback.Pin`), effets en marche, absente de la liste des lectures ; suit les rechargements du modèle ; `SceneId` nul = arrêt.
