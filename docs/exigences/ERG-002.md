## Description

> **Enregistrement de la disposition** : sans bouton, dès qu'elle change (vérification toutes les 2 s) et à la fermeture ; reprise au démarrage, fenêtres détachées et panneaux fermés compris ; une par disposition prête ; « Rétablir la disposition » revient à celle livrée ; un fichier illisible est mis de côté et la disposition livrée reprend, avec un message, sans jamais bloquer le démarrage.

**Critère d'acceptation** : Tests automatiques (écriture / relecture / fichier illisible) ; essai utilisateur (fermer, rouvrir).

## Réalisation

- `LayoutStore` (enveloppe `formatVersion` 1 via `VersionedJsonFile`, texte Dock conservé), `LayoutFile`, `ShellViewModel.SaveIfChanged` / `ResetLayout`.

## Tests

- LayoutStoreTests (écriture / relecture des deux dispositions, proportion modifiée, panneau fermé, fichier absent, illisible, enveloppe valide mais disposition cassée, suppression)
- Captures : fenêtre détachée relue (1 → 1)
