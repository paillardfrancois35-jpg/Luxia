## Description

> Les étiquettes de sûreté (`strobe`, `fumée`) sont déduites de l'attribut et modifiables (ex. un canal « Programme » dont une plage est un strobe).

**Critère d'acceptation** : Plage de strobe dans un canal programme → étiquetée.
