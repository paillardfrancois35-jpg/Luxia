## Description

> **Ancrage de panneaux** (bibliothèque *Dock*, Avalonia 12) : chaque panneau se colle à gauche / droite / haut / bas, s'empile en onglets, se **détache dans une fenêtre** (deuxième écran), se replie sur un bord ou se ferme ; un panneau fermé ou absent se réaffiche par le menu **Panneaux**, à sa place d'origine. Deux dispositions prêtes : **Contrôle** et **Spectacle** (§6).

**Critère d'acceptation** : Prototype (§7.2) : manipulations faites par l'utilisateur ; test automatique du réaffichage.

## Réalisation

- `tools/Luxia.Tools.Prototype` : `PrototypeDockFactory` (dispositions Contrôle / Spectacle), `PanelTemplate` (contenu par identifiant), `DockTree`, menu Panneaux (`MainWindow`).
- `Luxia.UI.Modules.Control/Docking` (ControlDockFactory, ControlPanelTemplate, DockTree), `Views/DockStrings.fr.axaml`, `Views/ControlView`.
