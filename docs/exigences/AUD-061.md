## Description

> **Niveaux** discrets avec hystérésis : **Calme**, **Groove**, **Énergique**, **Explosif**. Les seuils s'**adaptent** à l'historique récent (la soirée entière n'est pas « Explosif » juste parce que le volume est fort).

**Critère d'acceptation** : Pas d'oscillation rapide entre deux niveaux.
