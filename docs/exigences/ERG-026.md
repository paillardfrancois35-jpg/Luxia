## Description

> **Stop et Tout stopper** en tête de l'écran Contrôle : « ■ Stop » arrête toutes les scènes sauf les couches protégées (Ambiance par défaut, réglable dans Couches…, colonne Protégée) ; « ■ Tout stopper » arrête tout ; permis sous le verrou soirée.

**Critère d'acceptation** : Test.

## Réalisation

- `ControlViewModel.StopAll` (paramètre « tout »), deux boutons de `ControlView`.
