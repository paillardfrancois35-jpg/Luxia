## Description

> Les durées sont exprimées **soit en secondes** (résolution 1 ms), **soit en temps musicaux** (temps, fraction de temps, mesures). Le choix se fait par durée (étape, fondu, effet).

**Critère d'acceptation** : Test : étape de « 2 temps » à 120 BPM dure 1,000 s ; à 90 BPM 1,333 s.
