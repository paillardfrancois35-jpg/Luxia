## Description

> **Type d'effet lisible** : le panneau Effets affiche le type de l'effet (Intensité, Mouvement, Couleur) et ce qu'il anime ; la liste des formes ne propose que celles de ce type (le type vient du modèle et ne change plus par un simple choix de forme) ; le nom de l'effet porte « (modifié) » quand sa forme n'est plus celle du modèle.

**Critère d'acceptation** : choisir les 4 PAR, le modèle « Arc-en-ciel en vague » : la liste des formes ne propose que Arc-en-ciel, Alternance, Dégradé ; choisir « Dégradé » garde un effet de couleur, nommé « … (modifié) ».

## Réalisation

- `EffectsPanelViewModel` : `FamilyShapes`, `FamilyText`, `ShapeLabel` (Courbe / Trajectoire / Mode de couleur), `Modified` ; `EffectsPanelView.axaml` : ligne « Type : … » et liste filtrée.
- Principe documenté au [doc 16b](../16b-effets-fonctionnement.md), y compris plusieurs effets d'une même étape sur des appareils différents.
