| **Remarque** | Fenêtre « Base musicale » (bouton « Base… » du bloc « Morceau en cours »), onglet Base en **« liste + fiche »** (ERG-040, doc 60 §4.11) : à gauche la liste (recherche, filtre « Seulement Inconnu », Ajouter / Dupliquer / Supprimer / Chercher les doublons toujours au même endroit, export et import JSON), à droite la fiche (nom, style en **liste déroulante**, alias et titres saisis dans leurs listes avec « + », Enregistrer / Annuler, indicateur de modification). Un enregistrement refusé (alias déjà pris, nom pris, nom vide) garde la fiche ouverte et dit pourquoi. |

## Description
