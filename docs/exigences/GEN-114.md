## Description

> Menu **Aide → À propos** : boîte de dialogue en lecture seule, copiable, avec de quoi diagnostiquer un problème
> à distance (exécutable, répertoire de travail, PID, .NET/OS, dossiers de données, fichier de préférences,
> dernier projet en mémoire vs projet réellement ouvert, sortie configurée).

**Critère d'acceptation** : Le texte copié suffit à comprendre un problème signalé par l'utilisateur sans accès à son poste.

## Réalisation

- `src/Luxia.UI.Controls/IDialogService.cs` : `ShowInfoAsync`
- `src/Luxia.App/Services/DialogService.cs` : boîte en lecture seule + bouton Copier (presse-papiers)
- `src/Luxia.App/ViewModels/MainWindowViewModel.cs` : `ShowAboutCommand`, `BuildDiagnostics`
- `src/Luxia.App/MainWindow.axaml` : menu « _Aide »

## Tests

- Aucun test automatique (boîte de dialogue) ; `FakeDialogs.ShowInfoAsync` dans `tests/Luxia.UI.Tests/TestHost.cs` pour ne pas casser la compilation des autres tests.
