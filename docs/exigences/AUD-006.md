## Description

> L'analyse audio fonctionne dans son propre fil d'exécution ; une erreur de capture ne perturbe ni le moteur ni l'interface (GEN-093) ; reconnexion automatique.

**Critère d'acceptation** : Débrancher un casque USB → alerte, reprise.
