## Description

> Un **décalage de latence global** (± 250 ms) permet d'avancer ou de retarder tous les événements musicaux pour compenser la latence audio et celle des appareils.

**Critère d'acceptation** : Réglage visible ; test : décalage de −100 ms → événements émis 100 ms plus tôt que la détection brute.
