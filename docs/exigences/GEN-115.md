## Description

> Une seule instance de l'application à la fois (verrou au démarrage) : deux processus se disputeraient le port
> série de l'Arduino et pourraient perdre le « dernier projet » des préférences.

**Critère d'acceptation** : Lancer une deuxième instance affiche un message et se ferme, sans toucher aux
préférences ni au port série ; la première continue normalement.

## Réalisation

- `src/Luxia.App/Program.cs` : `Mutex` nommé, `MessageBox` (`user32.dll`) si une instance existe déjà.

## Tests

- Aucun test automatique (comportement au niveau processus / OS) ; vérifié manuellement en lançant deux
  `LuXia.exe` à quelques centaines de ms d'écart.
