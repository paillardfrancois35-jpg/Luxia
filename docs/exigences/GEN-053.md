## Description

> Le projet contient une **copie des modèles d'appareils** qu'il utilise. Une modification de la bibliothèque n'est répercutée dans le projet que sur action explicite, avec la liste des impacts.

**Critère d'acceptation** : Modifier un modèle dans la bibliothèque → projet inchangé ; « Mettre à jour » → rapport d'impacts.

## Réalisation

- `src/Dmx.Patch/ProjectFixtureLibrary.cs` : copie (`EnsureCopied`, au patch) et mise à jour explicite (`UpdateFrom`) dans `<projet>/Bibliothèque/`, même format que la bibliothèque partagée ; les génériques de l'application n'y sont jamais copiés (D24).
- `src/Dmx.Patch/Rules/FixtureUpdateImpact.cs` : rapport d'impact (canaux perdus / gagnés), réutilisé pour INST-016 (changer de mode) et la mise à jour depuis la bibliothèque partagée.
- `src/Dmx.Hosting/ProjectSession.cs` : `FixtureLibrary` ouvert à l'ouverture du projet.
- `src/Dmx.UI.Modules.Installation/InstallationViewModel.cs` : bouton « Mettre à jour » par appareil (`UpdateFromLibraryAsync`), avec confirmation si impact.
