## Description

> Estimation du tempo dans une plage réglable (défaut 70-180 BPM), précision ± 1 BPM sur musique rythmée, convergence en < 8 s après le début d'un morceau.

**Critère d'acceptation** : Jeu de référence (§7) : ≥ 90 % des morceaux dansants à ± 2 BPM (hors erreurs d'octave).
