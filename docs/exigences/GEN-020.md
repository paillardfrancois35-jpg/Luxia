## Description

> En interne, toute valeur d'attribut est une **valeur logique normalisée** entre 0 et 1, avec une résolution au moins équivalente à 16 bits. La conversion en 8 ou 16 bits DMX se fait uniquement à la sortie du moteur.

**Critère d'acceptation** : Test : 0,5 sur un attribut 8 bits → 128 ; sur 16 bits → 32768 (0x80/0x00).
