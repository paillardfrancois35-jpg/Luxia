## Description

> Un attribut 16 bits est décrit comme **un seul attribut** occupant deux canaux (grossier + fin), les deux étant positionnés indépendamment dans chaque mode.

**Critère d'acceptation** : Pan 16 bits en CH1 + CH2 → pad Pan unique.
