| Champ | Valeur |
|---|---|

| **Liens** | GEN-110, GEN-093 |

## Description

> **Toute exception** est écrite dans le journal technique, d'où qu'elle vienne : interface, autres fils, tâches de fond, et valeur refusée par un champ de saisie ; une erreur d'interface est aussi signalée dans la barre d'état.

**Critère d'acceptation** : Une exception levée en saisissant une valeur apparaît dans le journal technique avec sa pile d'appels.
