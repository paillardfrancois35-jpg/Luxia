## Description

> Formes de couleur : arc-en-ciel, alternance, dégradé entre palettes.

**Critère d'acceptation** : —

## Réalisation

- Arc-en-ciel (36 teintes interpolées), alternance (en escalier), dégradé (interpolé, revient à la première couleur) ; couleurs données une à une (couleur ou palette) ou par un thème (PAL-010). Chaque couleur est traduite selon les émetteurs de l'appareil (RVB, RVBW, roue) en une table par canal (`EffectShape.Table`). Toujours absolu.
