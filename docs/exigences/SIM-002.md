# SIM-002 – Rendu 30 images/s sans ralentir le moteur

| Champ | Valeur |
|---|---|
| **Statut** | Réalisé |
| **Priorité** | I |
| **Phase** | P3 |
| **Source** | [doc 14 – 4. Exigences](../14-simulateur.md) |
| **Remarque** | Mesure de trames/s non instrumentée ; le mécanisme (lecture non bloquante) est le même que le moniteur de la console, déjà en service depuis P1 sans ralentir le moteur. |
| **Liens** | GEN-013, SORT-062 |

## Description

> Rendu à 30 images/s minimum, synchronisé sur la dernière trame reçue ; le simulateur ne ralentit jamais le moteur (GEN-013).

**Critère d'acceptation** : Mesure.

## Réalisation

- `src/Dmx.UI.Modules.Simulator/SimulatorViewModel.cs` : `Refresh()` appelé par la coquille de l'application (même rythme que les autres écrans, ~20 Hz), lit `RenderEngine.CopyLastFrame` (copie protégée par verrou court, non bloquante pour le tick).

## Tests

- Aucune mesure automatique de trames/s : à instrumenter si un ralentissement est constaté en usage (comme GEN-090/091 pour la console).
