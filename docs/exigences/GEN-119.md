# GEN-119 – Numéro de compilation affiché en développement

| Champ | Valeur |
|---|---|
| **Statut** | Réalisé |
| **Priorité** | M |
| **Phase** | P4 |
| **Source** | [doc 02 – 16b. Diagnostic et robustesse](../02-principes-et-architecture-fonctionnelle.md) |
| **Remarque** | `LuxiaDevVersion` (Directory.Build.props) + compteur `build/numero-de-compilation-<version>.txt` hors dépôt, propre à chaque version de développement, augmenté par la cible `LuxiaBuildNumber` de Luxia.App. |
| **Liens** | GEN-114, doc 03 §7 |

## Description

> En développement, la version affichée porte un numéro de compilation qui augmente à chaque compilation ; une fois validée, la version seule.

**Critère d'acceptation** : Deux compilations successives affichent deux numéros différents.

## Réalisation

- `Directory.Build.props`
- `src/Luxia.App/Luxia.App.csproj`
- `src/Luxia.App/ViewModels/MainWindowViewModel.cs`

## Tests

- Vérifié à la compilation (message « LuXia : version 1.003.NNN ») ; contrôle visuel par l'utilisateur dans la barre de titre.
