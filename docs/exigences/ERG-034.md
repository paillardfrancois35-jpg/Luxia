## Description

> **Aperçu du brouillon** : hors aveugle, le brouillon est montré sur la sortie (CMD-017) ; **Appliquer** met à jour la scène sans fermer ; case **Aveugle** = aperçu au plan seulement, sortie inchangée (reformule GEN-063, SCN-035) ; l'état d'origine est restauré à l'annulation.

**Critère d'acceptation** : Tests.
