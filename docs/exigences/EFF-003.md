## Description

> Formes de position : cercle, huit, balayages, aléatoire lent ; appliquées autour d'un centre (palette de position).

**Critère d'acceptation** : Cercle autour de « Piste centre ».

## Réalisation

- Cercle, huit, balayages Pan / Tilt, aléatoire lent (continu d'un cycle à l'autre). Taille en degrés convertie selon la course Pan / Tilt du modèle (540° / 270° si le modèle ne la donne pas). Centre = palette de position (lieu actif, PAL-004 ; absolu), sinon la position de l'étape ou la position sous-jacente (relatif), sinon le milieu de la course.
