## Description

> Combinaison de deux effets sur un même attribut (ex. cercle + balayage) par addition.

**Critère d'acceptation** : —

## Réalisation

- Les écarts des effets relatifs d'un même attribut s'additionnent (`Playback.EffectOffset`) ; deux effets absolus se combinent selon leur poids (le suivant l'emporte).
