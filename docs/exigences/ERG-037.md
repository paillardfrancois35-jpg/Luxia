## Description

> **Dimmers de groupe** : panneau « Groupes dimmer » de l'écran de jeu (un fader par groupe à dimmer) ; le moteur multiplie l'intensité des appareils **après** la fusion des couches par chaque étage de l'arbre (règle proportionnelle : Maître × G1 × G1.1) ; appareil RVB sans canal d'intensité : les canaux émetteurs sont multipliés ; retouche non enregistrée (Q37).

**Critère d'acceptation** : Tests moteur.

## Réalisation

- `src/Luxia.Engine/Model/DimmerGroup.cs`, `ShowModel` (`DimmerGroups`, `ParameterGroups`, `IndexOfDimmerGroup`)
- `src/Luxia.Engine/RenderEngine.cs` (`ApplyMasters` : niveau effectif par groupe, multiplication des intensités après le Grand Master ; niveaux gardés à `ApplyShow`)
- `src/Luxia.Engine/EngineSnapshot.cs` (`DimmerLevels`, `DimmerEffective`)

## Tests

- `GroupDimmerTests` (9 tests : moitié d'intensité sans toucher aux couleurs, arbre, règle proportionnelle, intensité virtuelle, Grand Master, refus, rechargement, blackout, arbre invalide)
