## Description

> **Colonnes de l'écran Contrôle** : toutes les couches par priorité (sauf masquées), toutes leurs scènes (masquées du Live estompées) ; bouton à deux zones (jouer / ✎) ; ◀ ▶ ■ et master par couche ; « + scène » ; clic droit : Éditer, Renommer, Dupliquer, Couleur, Couche, Montrer / masquer dans le Live, Supprimer (annulable).

**Critère d'acceptation** : Tests.
