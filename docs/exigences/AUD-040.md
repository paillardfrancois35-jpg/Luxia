## Description

> Détection des attaques dans deux bandes : **basses** (grosse caisse, ~40-150 Hz) et **aigus** (caisse claire, claps, charleston, ~2-10 kHz).

**Critère d'acceptation** : Jeu de test annoté : ≥ 85 % des kicks détectés, < 10 % de fausses détections.
