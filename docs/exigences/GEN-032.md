## Description

> Les calculs du moteur utilisent le **temps écoulé réel** (et non le nombre de ticks) : un tick en retard ne ralentit pas les fondus.

**Critère d'acceptation** : Test : ticks irréguliers simulés → fondu de 2 s terminé à 2 s ± 1 tick.
