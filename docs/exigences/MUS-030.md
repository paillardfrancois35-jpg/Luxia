## Description

> Un morceau d'un **artiste absent de la base** y ajoute cet artiste avec le style « Inconnu » (une seule fois), pour le classer ensuite.

**Critère d'acceptation** : Jouer deux titres d'un inconnu : une seule fiche, style « Inconnu ».
