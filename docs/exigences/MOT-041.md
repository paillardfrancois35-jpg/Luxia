## Description

> Option du programmeur (active par défaut) : **« allumer en coloriant »** — donner une couleur à un appareil dont l'intensité est à 0 dans le programmeur ajoute l'intensité 100 % à l'enregistrement.

**Critère d'acceptation** : Scène « couleurs » créée depuis zéro → appareils allumés.
