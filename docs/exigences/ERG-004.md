## Description

> **Sélecteur de couleur** (composant commun, §5) : carré teinte × saturation, barre d'intensité, valeurs lisibles (°, %), **favoris** (clic = reprendre, clic droit = retirer, « + » = ajouter).

**Critère d'acceptation** : Tests des conversions et du découpage ; galerie ; essai utilisateur.

## Réalisation

- `Luxia.UI.Controls.ColorPicker`, `ColorPickerLayout`, `LightColor` (teinte, saturation, intensité ↔ RVB).

## Tests

- LightColorTests (couleurs connues, aller-retour RVB exact sur 4 096 couleurs, bornes)
- ColorPickerLayoutTests
