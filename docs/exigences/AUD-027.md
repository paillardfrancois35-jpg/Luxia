## Description

> **Décalage de latence** global réglable ± 250 ms (GEN-035) avec un outil de calibration : un appareil flashe sur chaque temps, l'utilisateur ajuste jusqu'à ce que le flash tombe sur le kick.

**Critère d'acceptation** : Calibration effectuée en < 1 min.
