## Description

> **Seconde platine MIDI** : deuxième contrôleur reconnu à part (par son port, MIDI-005) ; ses 8 premiers faders commandent les 8 premiers dimmers de groupe, dans l'ordre du panneau ; la première platine garde les couches ; affectation fixe (l'apprentissage « Affecter… », MIDI-008, reste reporté).

**Critère d'acceptation** : Tests ; essai matériel.

## Réalisation

- `src/Luxia.Midi/MidiRole.cs` (`MidiRole`, `MidiRoles.Assign`), `MidiController` (`Role`, `DimmerPage`, faders 1-8, bas 1-8, Maj + bas 3/4, LED), `MidiService` (rôles appliqués à chaque traitement, journal, `Connected`), `MidiLayout.Dimmers` / `DimmerController`, `MidiSettings.DimmerController`, `LuxiaRuntime.BuildMidiLayout`
- doc 50 §12d, doc 18b, `docs/schemas/midi.schema.json`
