## Description

> **Seconde platine MIDI** : deuxième contrôleur reconnu à part (par son port, MIDI-005) ; ses 8 premiers faders commandent les 8 premiers dimmers de groupe, dans l'ordre du panneau ; la première platine garde les couches ; affectation fixe (l'apprentissage « Affecter… », MIDI-008, reste reporté).
