## Description

> **Quantification du lancement** : une scène peut attendre le prochain temps, la prochaine mesure ou la prochaine phrase (4 ou 8 mesures) pour démarrer.

**Critère d'acceptation** : Lancement en milieu de mesure → démarre au 1er temps suivant.
