## Description

> Correction d'**octave** : préférence pour la plage 90-150 BPM en cas d'ambiguïté (réglable) ; commandes ×2 et ÷2 (CMD-042).

**Critère d'acceptation** : 64 BPM détecté sur un morceau à 128 → ×2 corrige et reste mémorisé pour le morceau.
