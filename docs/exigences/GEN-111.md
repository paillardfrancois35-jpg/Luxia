## Description

> **Journal de soirée** : pour chaque morceau, heure, titre, artiste, style détecté (et méthode, confiance), corrections manuelles, shows joués. Réutilisable pour enrichir la base musicale à la maison.

**Critère d'acceptation** : Après une répétition, le journal liste tous les morceaux.
