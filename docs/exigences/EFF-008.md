## Description

> Effets sur **cellules** (segments de barre, têtes de l'effet multi-têtes).

**Critère d'acceptation** : Chenillard sur les 16 segments des 2 barres.

## Réalisation

- `SceneEffect.PerCell` : chaque cellule de chaque membre devient un membre, dans l'ordre (barre 1 puis barre 2, segment par segment). Effet multi-têtes WZYBUTA repatché en **64 canaux à l'adresse 181** (Q25) : 12 têtes RVBW.
