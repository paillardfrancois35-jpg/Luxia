# MOT-082 – Zones interdites

| Champ | Valeur |
|---|---|
| **Statut** | Partiel |
| **Priorité** | I |
| **Phase** | P5 |
| **Source** | [doc 15 – 9. Sûreté](../15-moteur-de-rendu.md) |
| **Remarque** | Rectangles Pan/Tilt par lyre et par lieu, cible ramenée au bord autorisé le plus proche ; une zone qui touche une butée (0 ou 100 %) s'étend au-delà. Option « intensité à 0 pendant la traversée » non réalisée (demande un modèle de vitesse des moteurs). |
| **Liens** | GEN-085, INST-053, Q30, SIM-008 |

## Description

> **Zones interdites** : si la cible Pan/Tilt d'une lyre tombe dans une zone interdite du lieu actif, elle est ramenée au point autorisé le plus proche ; option : intensité de la lyre à 0 tant que sa position estimée traverse une zone.

**Critère d'acceptation** : Test.
