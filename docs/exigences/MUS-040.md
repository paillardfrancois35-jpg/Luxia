## Description

> Pour une liste d'artistes / titres (« À classer », playlists importées), interroger des sources en ligne d'étiquettes musicales (ex. Last.fm, MusicBrainz, Deezer, Discogs) et **proposer** une famille via la taxonomie.

**Critère d'acceptation** : Proposition pour 100 artistes.

## Réalisation

- `src/Luxia.Music.Enrichment/TagSources.cs` (`MusicBrainzSource`, `LastFmSource`), `Enricher.cs`
- `src/Luxia.Music/Classification/Proposals.cs` (`TagMapper`, `Proposal`, `ProposalSet`)
- `tools/Luxia.Tools.MusicEnrich/Program.cs`
