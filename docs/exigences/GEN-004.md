## Description

> Un composant d'édition (ex. faders d'appareil) doit pouvoir être intégré dans un autre écran (ex. éditeur de bibliothèque pour le test en direct).

**Critère d'acceptation** : Le test en direct de la bibliothèque réutilise le composant de la console.
