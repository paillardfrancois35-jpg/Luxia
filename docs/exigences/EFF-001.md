## Description

> Ajouter un ou plusieurs effets à une étape, avec les paramètres du §6.1.

**Critère d'acceptation** : —

## Réalisation

- Données : `SceneStep.Effects` (liste de `SceneEffect` : cible, forme, attribut, durée d'un cycle, taille, centre, palette de position, relatif, décalage et répartition de phase, sens, rapport cyclique, couleurs ou thème, cellules). Format dans `scènes.json` (champ facultatif, format 1 inchangé : un fichier antérieur se relit tel quel).
- Compilation : `EffectCompiler` (cible → membres ordonnés, retard de phase, degrés → course du modèle, couleurs → tables par canal) ; un effet sans effet possible est signalé (`valider`, Problèmes du projet) et écarté.
