# BIB-093 – Groupe fabricant non déplié après une recherche

| Champ | Valeur |
|---|---|
| **Statut** | À faire |
| **Priorité** | S |
| **Phase** | P2 |
| **Source** | Test utilisateur du guide P2 (exemple 1), 2026-09-25 |
| **Remarque** | Extension de BIB-020. |
| **Liens** | BIB-020 |

## Description

> Après une recherche ou un filtre (ex. « UV »), le fabricant correspondant apparaît dans la liste, mais son groupe n'est pas
> déplié automatiquement : le modèle filtré (ex. BUV463 chez BeamZ) reste caché tant qu'on ne déplie pas la ligne à la main.

**Comportement attendu** : une recherche ou un filtre actif déplie automatiquement les groupes qui contiennent un résultat.

**Critère d'acceptation** : taper « UV » dans la recherche affiche directement la ligne BUV463 sous BeamZ, sans clic supplémentaire.
