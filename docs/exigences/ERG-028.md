## Description

> **Molette** (composant commun, §5) : arc de la valeur à la couleur du mode, valeur et libellé ; glisser vers le haut / la droite (200 pixels = toute la course), molette de la souris ± un pas (Maj : × 10), flèches, double-clic = valeur par défaut ; liée dans les deux sens.

**Critère d'acceptation** : Tests ; captures.

## Réalisation

- `Dial` (Luxia.UI.Controls) : dessiné à la main, lié dans les deux sens ; `Dial.Fraction` pour la position dans la course.

- `EffectsPanelTests.Dials_WriteIntoTheEffect_OneGesture`
