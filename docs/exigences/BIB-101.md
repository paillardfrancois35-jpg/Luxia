## Description

> Canal Strobe du LPC008S, du LPC120 et de la LCB803 : plage « Pas de strobe » distincte de la plage de strobe, pour que
> le simulateur, `jouer` et le limiteur de strobe (MOT-080) ne prennent pas un appareil qui éclaire fixe pour un strobe.

**Critère d'acceptation** : LPC008S : 0-4 néant, 5-255 strobe ; LCB803 : 0 néant, 1-255 strobe ; LPC120 comme le LPC008S.

  et leurs copies dans `samples/Show de référence/Bibliothèque/` (GEN-053).
- `samples/Bibliothèque/generer.py` (script d'amorçage aligné).

## Tests

- `ShowCompilerTests.Parameters_OfReferenceRig_HaveRolesAddressesAnd16Bits` : le canal Strobe du LPC008S devient discret
  (une plage fixe + une progressive, MOT-012), comme celui de l'UV BUV463.
